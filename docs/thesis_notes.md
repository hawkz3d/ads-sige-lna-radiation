# 论文技术笔记

## 1. 研究对象与背景

- **器件**：SiGe HBT 及其 MMIC LNA，应用于近地空间（范艾伦辐射带）极端辐射环境。
- **两大退化因素**：辐射损伤（TID 总剂量效应 + DD 位移损伤）与电磁干扰（EMI），
  及其协合效应。
- **方法**：Sentaurus TCAD 器件级仿真 → SPICE 参数提取 → ADS 电路级仿真 →
  239Pu α 粒子辐照实验验证。

## 2. 器件与工艺

- **工艺**：0.18 μm SiGe BiCMOS，NPN 射频晶体管，某商用样品 NXP NGU2325。
- **TCAD 结构**：基区/发射区/集电区采用均匀 + 高斯混合掺杂，
  基区为薄硼掺杂，发射区为内凹台阶多晶硅。

## 3. TCAD 辐照仿真（Sentaurus）

在基区相邻界面及沟槽氧化层处添加受主缺陷能级，模拟电离损伤（TID）；
在 SiGe 基区与集电区体内添加缺陷，模拟位移损伤（DD）。

### 3.3 关键结果

- 测量条件：VC=1.5V，扫描 VB 0.5–1.1V（正向/反向 Gummel 曲线）。
- **VBE=0.767V** 时增益退化：
  - TID：βf 272.8 → 229.1（退化率 0.839），βr 443.1 → 316.0
  - DD：βf 272.8 → 233.0（退化率 0.854），βr 443.1 → 368.8
- **BC 结电容**：0.335 fF → 0.350 fF（TID 后）；BE 结电容略微降低。
- 退化主要发生在低偏置区（VBE < 0.7V）；DD 效应轻于 TID
  （疑似离子注入式退火）。

## 4. LNA 设计与 ADS 仿真（第4章核心）

### 4.1 电路结构（Cascode）

- 三部分：偏置电路 + Cascode 放大级 + 输出匹配网络。
- 静态工作点（DC 扫描）：VCE=1.1V，IC=272 μA，IB=1 μA，β=272.2。
- 偏置电路：带隙基准启动 → 电流镜。Q1 电流镜、Q2 地通路、Q3 基极补偿、
  Q5 cascode 偏置、Q6/Q7 放大级。
- 中心频率 **0.7 GHz**；共轭匹配下最高功率增益 19.4 dB，最小噪声系数 1.4 dB。

### 4.2 设计指标（表4-1）

| 性能参数 | 设计指标 |
|----------|----------|
| 频率 | 700 ± 10 MHz |
| S11 输入反射 | ≤ −5 dB |
| S22 输出反射 | ≤ −10 dB |
| NF 噪声系数 | ≤ 1.9 dB |
| S21 功率增益 | ≥ 18 dB |

仿真实现：中心频带 S21 ≈ 18.5 dB、NF < 2 dB、S11 最低 −8.3 dB、S22 最低 −16.2 dB。

### 4.3 辐照参数（表4-3，见 `netlist/radiation_models.md`）

通过修改 SPICE 参数（BF/RB/CJE/CJC/TF）模拟 TID/DD 退化。

### 4.4 仿真结果汇总

| 工况 | S11 | S22 | NF | S21 |
|------|-----|-----|----|-----|
| 设计值 | ≤−5 | ≤−10 | ≤1.9 | ≥18 |
| TID 后 | ≤−3 | ≤−20 | ~2.5 | ~15 |
| DD 后 | ≤−5 | ≤−10 | ≤2.1 | ~18 |
| TID+EMI | ≤−13 | ≤−15 | ~4.0 | ≥13 |
| DD+EMI | ≤−11 | ≤−12 | ~3.5 | ≥15 |

- TID：S21 最多衰退 2.2 dB，S11 增大（输入匹配恶化），NF 明显恶化。
- DD：退化更轻（BF 衰减较小 + 退火效应）。
- EMI 协合：S21 相对辐照前衰减达 3.2 dB 以上，S22 最多增加约 10 dB。

### 4.5 EMI 注入方法

- 在 Cascode 放大级晶体管基极前加 **−15 dBm / 500 MHz** 信号源。
- 第一级放大晶体管结上施加瞬态电流源，模拟 BE 结整流效应。
- 输入前端加周期 2 ns、幅值 2V 的方波观察时域波形。
- 机理：交流整流效应改变直流工作点 + 增益退化协合，导致参数严重偏移。

## 5. α 粒子辐照实验（第5章）

- 源：**239Pu α 源**，α 粒子能量约 5 MeV，源直径约 25 mm。
- 样品：4 片 NXP BGU7005（1#/2#/10#/20#）+ 1 片空白对照（15#）。
- 工作条件：偏置 2.5V / 0.012A，芯片面积 9.24×10⁻⁴ cm²。
- 测量：矢量网络分析仪 AV3672B-S。
- 辐照前：S21 16–20 dB（1.4 GHz 带内），S11/S22 < −8 dB。
- 随注量增加：S11 变大、S22 减小、S21 减小、S12 略增、线性度变差。

## 6. 主要结论

1. **HBT 退化**：TID/DD 均在 SiO2 及 Si/SiO2 界面产生正氧化物陷阱电荷与界面态，
   基极复合电流增大 → β 下降；低偏置区退化更明显；结电容略增。
2. **LNA 退化**：增益下降、噪声系数增加、出入波损耗增大，核心是 HBT 增益退化 +
   结电容/基极电阻/截止频率参数退化；EMI 协合使退化加剧。
3. **α 辐照**：S11/S22/S21/S12/线性度随注量单调退化，与仿真趋势一致。
