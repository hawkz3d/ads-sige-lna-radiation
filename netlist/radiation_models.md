# SiGe HBT 辐照损伤 SPICE 模型参数

通过修改核心晶体管 SPICE 模型参数模拟辐照后的
电学性能退化（TID 总剂量效应 / DD 位移损伤），得到辐照前后 LNA 的
S 参数、噪声系数退化趋势。

## 核心参数对照表（论文表4-3）

| SPICE 参数 | 含义 | 辐照前 | TID 辐照后 | DD 辐照后 |
|------------|------|--------|-----------|----------|
| `BF`       | 正向直流电流增益 β | 272.8 | 229.1 | 233.0 |
| `RB` (`rb_ex`) | 基极串联电阻 | 15.3 Ω | 28.9 Ω | 20.3 Ω |
| `CJE` (`cje_ex`) | BE 结电容 | 26.9 fF | 32.1 fF | 25.3 fF |
| `CJC` (`cjc_ex`) | BC 结电容 | 33.4 fF | 36.9 fF | 35.1 fF |
| `TF` (`tf_ex`) | 正向渡越时间 | 0.34 ps | 0.31 ps | 0.31 ps |

## 退化物理机制

- **TID（总剂量效应）**：电离辐射在 SiO2 氧化隔离层及 Si/SiO2 界面产生
  正氧化物陷阱电荷与界面态陷阱 → 基极复合电流增大 → β 下降；
  氧化物陷阱将耗尽区扩展至氧化层 → 结面积增大 → `CJE`/`CJC` 增大。
- **DD（位移损伤）**：入射粒子碰撞晶格产生空位-间隙缺陷 → 复合中心增多，
  少子寿命下降 → β 下降；介电常数 εr 改变 → 结电容变化（BE 降、BC 增）。

## 对应关系（论文仿真结果）

| 性能参数 | 设计指标 | TID 后 | DD 后 | TID+EMI | DD+EMI |
|----------|----------|--------|-------|---------|--------|
| S11 输入反射 | ≤ -5 dB | ≤ -3 dB | ≤ -5 dB | ≤ -13 dB | ≤ -11 dB |
| S22 输出反射 | ≤ -10 dB | ≤ -20 dB | ≤ -10 dB | ≤ -15 dB | ≤ -12 dB |
| NF 噪声系数 | ≤ 1.9 dB | ± 2.5 dB | ≤ 2.1 dB | ± 4.0 dB | ± 3.5 dB |
| S21 功率增益 | ≥ 18 dB | ± 15 dB | ± 18 dB | ≥ 13 dB | ≥ 15 dB |

## 结论要点（论文 4.4 / 6.1）

1. 辐照后 S21 明显衰退，TID 最多达 2.2 dB；DD 引起的退化较轻
   （疑似离子注入式退火效应）。
2. S11 增大、S22 频带内基本不变频带外下降，源于 `RB` 增大 + 结电容
   变化引起的输入阻抗漂移。
3. EMI 协合效应会在 TID/DD 基础上进一步劣化增益、噪声与阻抗匹配
   （S21 相对辐照前衰减达 3.2 dB 以上），核心是 HBT 正向增益退化加剧
   + BE 结整流效应改变直流工作点。
